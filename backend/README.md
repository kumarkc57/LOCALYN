# Localyn Backend

## Overview

The **Localyn** backend is a FastAPI application that provides APIs for:
- Ward‑boundary look‑ups and GIS queries
- Event ingestion and fusion
- **Live weather intelligence for Bengaluru** (current temperature, precipitation, forecasts, and risk alerts)

It runs on Python 3.12 and uses a SQLite database (default) for persistence.

---

## Prerequisites

- **Python 3.12+**
- **pip** (installed with Python)
- (Optional) **uv** – a fast Python package manager. If you prefer `pip`, use the provided `requirements.txt`.

## Environment Variables

Create a **.env** file in the `backend/` folder (or set the variables in your shell). The following variables are read by the application:

| Variable | Description | Required | Default |
|----------|-------------|----------|---------|
| `OPENWEATHER_API_KEY` | API key for OpenWeatherMap (fallback, optional) | No | – |
| `OPENMETEO_ENDPOINT` | Base URL for Open‑Meteo (defaults to `https://api.open-meteo.com/v1/forecast`) | No | `https://api.open-meteo.com/v1/forecast` |
| `DATABASE_URL` | SQLAlchemy connection string (e.g., `sqlite:///localyn.db`) | No | `sqlite:///localyn.db` |
| `HOST` | Host interface for the server | No | `0.0.0.0` |
| `PORT` | Port number for the server | No | `8000` |

**Note:** The live‑weather endpoint uses **Open‑Meteo**, which does **not** require an API key. The `OPENWEATHER_API_KEY` is kept for backward compatibility.

## Running the Server

```bash
# Ensure the virtual environment is active (if you created one)
.venv\Scripts\activate

# Start FastAPI with hot‑reload (development mode)
uvicorn app.main:app --reload --host $HOST --port $PORT
```

The API will be reachable at `http://localhost:8000`.

## API Overview

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/wards/{ward_id}` | Retrieve GeoJSON for a specific ward |
| `GET` | `/events` | List recent events, optionally filtered by ward or date |
| `POST` | `/ingest` | Ingest new event data (used by background jobs) |
| `GET` | `/weather/live` | **Live weather for Bengaluru** (or any supported city) |
| `GET` | `/weather/forecast` | 7‑day forecast (currently unused by the UI) |

For full OpenAPI documentation, visit `http://localhost:8000/docs` after the server starts.

## Troubleshooting

- **“Module not found: uvicorn”** – Ensure you are in the virtual environment and that `uvicorn` is listed in `requirements.txt`.
- **Database errors** – Verify the `DATABASE_URL` points to a writable location. By default it creates `localyn.db` in the backend folder.
- **Rate‑limit warnings** – Open‑Meteo is free with generous limits; however, excessive calls may be throttled. Cache responses where possible.
- **Missing environment variables** – The server will start with defaults, but missing keys for optional services will be logged as warnings.
